AI and Math: A History · Static Website

Entry point: index.html

How to use:
1. Open index.html in a browser.
2. Edit css/style.css to adjust the design.
3. Edit js/data.js to update categories and timeline milestones across the English site.
4. js/main.js generates the shared page structure and interactions.

Pages:
- index.html: timeline
- future.html: questions about the future
- forum.html: discussion page
- progress/*.html: eight topic pages
- editable-timeline.html: a manually editable version of the English timeline

Use “Language · 中文” in the upper-right corner to return to the corresponding Chinese page.

This website requires no installation or build step.
